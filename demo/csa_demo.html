Built on the CSA engine (see DESIGN.md in the repository) — a domain-specific compressor for structured pose/geometry data, benchmarked honestly against gzip/bz2/lzma/zstd/brotli on real datasets (KITTI, EuRoC, TUM). This page compiles the identical C++ core to WebAssembly via Emscripten; it runs single-threaded in this sandboxed tab, so the interleaved-rANS panel measures correctness here, not the ~2.3×/3.6× real OS-thread speedup already measured on the native desktop build (see DESIGN.md's write-up). The GPU-accelerated paths are native-only and are not part of this in-browser build.
